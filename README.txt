Kshitij Restaurant website (static HTML, no build step)

Pages: index.html, menu.html, gallery.html, banquet.html, reserve.html, contact.html
Folders: images/ (photos, menu card pages, food), style.css, app.js, menu-data.js

HOW TO DEPLOY
- Netlify: go to app.netlify.com/drop and drag this whole folder in.
- Vercel / Cloudflare Pages: upload the folder as a static site (no build command, output directory is the root).
- GitHub Pages: push the files to a repo and enable Pages on the main branch.
- cPanel / any hosting: upload everything into public_html (index.html must stay at the root).

HOW TO EDIT
- Menu items and prices: menu-data.js
- Phone / WhatsApp number: search for 919924294440 in all .html files and app.js
- Photos: replace files in images/ keeping the same names
